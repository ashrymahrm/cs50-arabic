المؤشرات

ملاحظة تقنية: حجم المؤشر يعتمد على المنصة، وليس ثمانية بايتات في كل بيئات C. في الشيفرة المحمولة، تتوقع صيغة %p وسيطًا من النوع void *، لذا يُحوَّل المؤشر إليه عند الطباعة. أمثلة المصدر التعليمية محفوظة دون تعديل. مرجع التوضيح

  • تتضمن C عاملين مهمين للتعامل مع الذاكرة:

      & Provides the address of something stored in memory.
  * Instructs the compiler to go to a location in memory.

  • يمكن استخدام هذه المعرفة لتعديل الشيفرة:

    // Prints an integer's address

#include <stdio.h>

int main(void)
{
    int n = 50;
    printf("%p\n", &n);
}

    يتيح %p عرض عنوان في الذاكرة. التعبير &n يعني عنوان n. عند التشغيل ستظهر قيمة عنوان تبدأ عادة بـ 0x. رابط تنزيل المثال الأصلي مرفق. المصدر المرتبط

int *p = &n;

    المتغير p مؤشر يحمل عنوان العدد الصحيح n.

النسخ وحجز الذاكرة

  • كثيرًا ما نحتاج إلى نسخ سلسلة نصية.

  • اكتب code copy.c في الطرفية، ثم:

    // Capitalizes a string

#include <cs50.h>
#include <ctype.h>
#include <stdio.h>
#include <string.h>

int main(void)
{
    // Get a string
    string s = get_string("s: ");

    // Copy string's address
    string t = s;

    // Capitalize first letter in string
    t[0] = toupper(t[0]);

    // Print string twice
    printf("s: %s\n", s);
    printf("t: %s\n", t);
}

    التعليمة string t = s تنسخ العنوان المخزن في s إلى t. لا تنسخ المحارف نفسها. لاحظ تضمين ctype.h أيضًا. رابط المثال الأصلي مرفق. المصدر المرتبط

  • يمكن تمثيل ذلك هكذا:

    وصف الشكل: المؤشران s وt يحملان العنوان نفسه، فيشيران إلى سلسلة واحدة.

    يشير s وt إلى خانات الذاكرة نفسها. لدينا مؤشران إلى سلسلة واحدة، لا نسختان مستقلتان منها.

  • قبل معالجة النسخ، ينبغي تفادي الوصول غير الصحيح إلى الذاكرة. في هذا المثال نفحص طول السلسلة باستخدام strlen قبل تعديل أول محرف:

    // Capitalizes a string, checking length first

#include <cs50.h>
#include <ctype.h>
#include <stdio.h>
#include <string.h>

int main(void)
{
    // Get a string
    string s = get_string("s: ");

    // Copy string's address
    string t = s;

    // Capitalize first letter in string
    if (strlen(t) > 0)
    {
        t[0] = toupper(t[0]);
    }

    // Print string twice
    printf("s: %s\n", s);
    printf("t: %s\n", t);
}

    يُستخدم strlen للتحقق من وجود محارف في السلسلة. إذا كانت فارغة لا يُعدَّل أول محرف. رابط المثال الأصلي مرفق. [ملاحظة تحريرية: هذا الفحص لا يغني عن التحقق من NULL قبل استدعاء strlen.] المصدر المرتبط

  • نحتاج إلى أداتين لنسخ المحارف إلى مساحة مستقلة: malloc تحجز كتلة ذاكرة بالحجم المطلوب، وfree تحرر تلك الكتلة عندما ننتهي منها.

  • يمكن تعديل الشيفرة لإنشاء نسخة مستقلة:

    // Capitalizes a copy of a string

#include <cs50.h>
#include <ctype.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

int main(void)
{
    // Get a string
    char *s = get_string("s: ");

    // Allocate memory for another string
    char *t = malloc(strlen(s) + 1);

    // Copy string into memory, including '\0'
    for (int i = 0; i <= strlen(s); i++)
    {
        t[i] = s[i];
    }

    // Capitalize copy
    t[0] = toupper(t[0]);

    // Print strings
    printf("s: %s\n", s);
    printf("t: %s\n", t);
}

    تحجز malloc(strlen(s) + 1) مساحة لطول السلسلة زائد بايت لمحرف النهاية \0. تنقل حلقة for كل محرف من s إلى الموضع المقابل في t. رابط المثال الأصلي مرفق. المصدر المرتبط

  • لكن التنفيذ غير فعّال. عدّله هكذا:

    // Capitalizes a copy of a string, defining n in loop too

#include <stdio.h>

القيم غير المهيأة

ملاحظة تقنية: قراءة قيم محلية أو محجوزة لم تُهيأ قد تؤدي إلى سلوك غير معرّف في C. المثال التعليمي محفوظ لفهم المشكلة، لا بوصفه أسلوبًا آمنًا لفحص الذاكرة. مرجع التوضيح
  • حجز كتلة ذاكرة لا يعني أن محتواها صفري أو مهيأ.

  • قد تكون هذه المساحة استُخدمت سابقًا، فتحتوي على قيم غير مهيأة نسميها أحيانًا قيمًا عشوائية أو مهملات. تأمل garbage.c:

    garbage.c 
    #include <stdio.h>
#include <stdlib.h>

int main(void)
{
    int scores[1024];
    for (int i = 0; i < 1024; i++)
    {
        printf("%i\n", scores[i]);
    }
}

    يحجز المثال مصفوفة من 1024 عنصرًا، لكن طباعة عناصر لم تُهيأ ليست طريقة آمنة للاعتماد على قيمها. لا تفترض أن الذاكرة الجديدة مليئة بالأصفار. رابط المثال الأصلي مرفق. المصدر المرتبط

تبديل القيم

  • نحتاج أحيانًا إلى تبديل قيمتين، وعادةً نستخدم متغيرًا مؤقتًا لحفظ إحداهما. اكتب code swap.c ثم:

    // Fails to swap two integers

#include <stdio.h>

void swap(int a, int b);

int main(void)
{
    int x = 1;
    int y = 2;

    printf("x is %i, y is %i\n", x, y);
    swap(x, y);
    printf("x is %i, y is %i\n", x, y);
}

void swap(int a, int b)
{
    int tmp = a;
    a = b;
    b = tmp;
}

    يعمل البرنامج لكنه لا يبدّل القيمتين في main بعد استدعاء swap. لماذا؟ رابط المثال الأصلي مرفق. المصدر المرتبط

  • عند تمرير القيم إلى دالة، تحصل الدالة على نسخ منها. المتغيران x وy في main لهما نطاق محلي داخل أقواسها، وما يمرر إلى swap هو قيمتاهما بالنسخ.

  • تأمل الرسم الآتي:

    وصف الشكل: تخطيط مبسط للذاكرة: شيفرة الآلة، المتغيرات العامة، الكومة Heap، والمكدس Stack.

    يعرض الرسم مناطق الذاكرة، ومنها المتغيرات العامة والكومة Heap والمكدس Stack. إطارات استدعاء الدوال توجد على المكدس.

  • وتأمل الرسم التالي:

    وصف الشكل: إطار main وإطار swap منطقتان منفصلتان في المكدس.

    للدالتين main وswap إطاران منفصلان. تغيير النسخة المحلية في swap لا يغير تلقائيًا متغير main.

  • عدّل الشيفرة:

    // Swaps two integers using pointers

#include <stdio.h>

void swap(int *a, int *b);

int main(void)
{
    int x = 1;
    int y = 2;

    printf("x is %i, y is %i\n", x, y);
    swap(&x, &y);
    printf("x is %i, y is %i\n", x, y);
}

void swap(int *a, int *b)
{
    int tmp = *a;
    *a = *b;
    *b = tmp;
}

الدالة scanf

  • وفّرنا في CS50 دوال مثل get_int لتسهيل استقبال مدخلات المستخدم.
  • تستقبل scanf مدخلات وفق صيغة محددة.

  • يمكن تنفيذ فكرة get_int باستخدام scanf:

    // Gets an int from user using scanf

#include <stdio.h>

int main(void)
{
    int n;
    printf("n: ");
    scanf("%i", &n);
    printf("n: %i\n", n);
}

    تكتب scanf("%i", &n) العدد المقروء في موضع المتغير n. رابط المثال الأصلي مرفق. المصدر المرتبط

  • لكن تنفيذ ما يشبه get_string ليس بهذه السهولة. تأمل:

    // Dangerously gets a string from user using scanf with array

#include <stdio.h>

int main(void)
{
    char s[4];
    printf("s: ");
    scanf("%s", s);
    printf("s: %s\n", s);
}

    لا نحتاج إلى & عند تمرير عنوان أول محرف. لكن المثال غير آمن: لم نحجز مساحة صالحة للسلسلة، ولا نعرف طول ما سيدخله المستخدم. رابط المثال الأصلي مرفق. المصدر المرتبط

  • قد نعدل الشيفرة بحجز مساحة محددة مسبقًا:

    // Using malloc

#include <stdlib.h>

int main(void)

    إذا احتاج المدخل إلى أربعة بايتات للمحارف وحدها، فلا تكفي مساحة أربعة بايتات لأنه يلزم أيضًا محرف النهاية.

  • يبسّط المثال الآتي المشكلة:

    #include <stdio.h>

    تتسع المصفوفة ذات الحجم 4 للكلمة cat ومحرف النهاية. المدخل الأطول قد يتجاوز المساحة المتاحة.

int main(int argc, char *argv[])
{
    FILE *src = fopen(argv[1], "rb");
    FILE *dst = fopen(argv[2], "wb");

    BYTE b;

    while (fread(&b, sizeof(b), 1, src) != 0)
    {
        fwrite(&b, sizeof(b), 1, dst);
    }

    fclose(dst);
    fclose(src);
}

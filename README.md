# CS50 بالعربي

Independent noncommercial Arabic adaptation of CS50x2026. Work in progress, not affiliated with or endorsed by Harvard or edX.

Teaching source: https://cs50.harvard.edu/x/2026/ by David J. Malan and CS50, Harvard University. Adapted teaching material: CC BY-NC-SA4.0, https://creativecommons.org/licenses/by-nc-sa/4.0/ . Source code examples retain their original licenses. Third-party asset exceptions remain.

This static deployment includes12lecture routes and Arabic Week0/1/2notes. Dubbed media and other translated materials are pending. Five third-party figures are explicitly withheld. Source errors are distinguished in editorial notes. No grades, enrollment, certificates or data collection.

One self-contained index.html supports bookmarkable hash lesson routes on GitHub Pages without broken deep-link404s or a build service. CSS, course data and translated readings are embedded. Retained figures load from the official CS50 notes pages. No secrets or build logs included.

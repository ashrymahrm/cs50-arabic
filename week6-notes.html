المدقق الإملائي

  • لرؤية هذه البساطة، اكتب code dictionary.py في الطرفية ثم:

    # Words in dictionary
words = set()


def check(word):
    """Return true if word is in dictionary else false"""
    return word.lower() in words


def load(dictionary):
    """Load dictionary into memory, returning true if successful else false"""
    with open(dictionary) as file:
        words.update(file.read().splitlines())
    return True


def size():
    """Returns number of words in dictionary if loaded else 0 if not yet loaded"""
    return len(words)


def unload():
    """Unloads dictionary from memory, returning true if successful else false"""
    return True

    لدينا أربع دوال. تفحص check وجود الكلمة في words وتعيد True عند وجودها. تفتح load ملف القاموس وتضيف كل سطر إلى words بعد إزالة المحارف البيضاء النهائية باستخدام rstrip. تعيد size عدد الكلمات باستخدام len، ولا تحتاج unload هنا إلا إلى إرجاع True لأن Python تدير الذاكرة. رابط المثال الأصلي مرفق. المصدر المرتبط

المتغيرات

  • في C كتبنا int counter = 0;، وفي Python نكتب counter = 0 من دون التصريح باسم النوع.
  • نستخدم counter += 1 للزيادة بواحد؛ لا يوجد عامل counter++ في Python.

الأنواع

  • لا يلزم التصريح بنوع المتغير، لكن القيم نفسها لها أنواع. كانت answer سلسلة نصية لأن دالة الإدخال أعادت سلسلة.

  • من الأنواع الشائعة في Python:

      bool
  float
  int
  str

    لا نستخدم هنا long وdouble كاسمي نوعين منفصلين. يدعم int أعدادًا صحيحة كبيرة بحسب الذاكرة المتاحة، وfloat أعدادًا ذات فاصلة عائمة محدودة الدقة.

  • وتوجد أنواع أخرى منها:

    range   sequence of numbers
list    sequence of mutable values
tuple   sequence of immutable values
dict    collection of key-value pairs
set     collection of unique values

  • وتذكّر مثال نسخ السلسلة في C:

    // Capitalizes a copy of a string without memory errors

#include <cs50.h>
#include <ctype.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

int main(void)
{
    // Get a string
    char *s = get_string("s: ");
    if (s == NULL)
    {
        return 1;
    }

    // Allocate memory for another string
    char *t = malloc(strlen(s) + 1);
    if (t == NULL)
    {
        return 1;
    }

    // Copy string into memory
    strcpy(t, s);

    // Capitalize copy
    if (strlen(t) > 0)
    {
        t[0] = toupper(t[0]);
    }

    // Print strings
    printf("s: %s\n", s);
    printf("t: %s\n", t);

    // Free memory
    free(t);
    return 0;
}

    لاحظ عدد سطور التنفيذ. رابط المثال الأصلي مرفق. المصدر المرتبط
